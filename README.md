# دليل غابة رغدان

موقع عربي مستقل غير ربحي عن غابة رغدان في منطقة الباحة، مبني بـ Astro + Tailwind CSS + TypeScript ومهيأ للنشر كأصول ثابتة على Cloudflare Workers عبر Wrangler.

## التشغيل

المتطلبات المثبتة في المشروع:

- Node.js `24.19.0`
- pnpm `11.23.0`

```bash
corepack enable
CI=1 corepack pnpm install --frozen-lockfile
pnpm check
pnpm run source:audit
pnpm build
```

## النطاق

لا يوجد نطاق افتراضي أو تجريبي. عند تحديد النطاق، مرره إلى عملية البناء من خلال المتغير `SITE_URL`؛ وهو يُقرأ في `astro.config.ts` ويُستخدم كقيمة `site` الوحيدة. عند تركه فارغاً يبقى البناء صالحاً، ولا يتم تشغيل تكامل خريطة الموقع ولا إخراج عنوان canonical مطلق.

اضبط `SITE_URL` على النطاق الحقيقي في بيئة البناء ثم نفّذ `pnpm build`. لا يضع المشروع أي نطاق تجريبي أو قيمة بديلة.

بعد ضبط نطاق حقيقي، ينشئ `@astrojs/sitemap` خريطة الموقع تلقائياً من صفحات Astro، من دون قائمة URL مكتوبة يدوياً أو قيم `lastmod` مختلقة.

## Cloudflare Workers

المشروع ثابت بالكامل، لذلك لا يستخدم محول Cloudflare الخاص بالتصيير عند الطلب. هذا يتبع توجيه Astro الرسمي للمواقع الثابتة. يقوم `wrangler deploy` برفع مجلد `dist` عبر Workers Static Assets وفق `wrangler.jsonc`.

```bash
pnpm deploy
```

## الصفحات

- `/` — الدليل الرئيسي
- `/privacy/` — سياسة الخصوصية
- `/terms/` — شروط الاستخدام
- `/cookies/` — إعدادات ملفات تعريف الارتباط

## الصور

الشعار وملفات favicon وبطاقة المشاركة محفوظة محلياً. الصور الفوتوغرافية الخمس مصدرها ويكيميديا كومنز بتراخيص عامة موضحة في الصفحة. جرى حصر الاستضافة الخارجية للصور في هذه الملفات الفوتوغرافية فقط لأن المشروع يحتاج صوراً حقيقية للغابة والمنطقة؛ يمكن لاحقاً تنزيل النسخ الأصلية إلى `public/images/` وتبديل المسارات من دون تغيير التصميم.

## التحليلات والخصوصية

معرّف GA4 هو `G-HXM22WWPKP`. لا يتم تحميل مكتبة التحليلات حتى يفعّل الزائر خيار التحليلات في صفحة إعدادات ملفات تعريف الارتباط. تحفظ الموافقة محلياً في المتصفح.

## تحويل الصور إلى ملفات محلية

إذا كانت بيئة العمل متصلة بالإنترنت، نفّذ `pnpm run images:vendor` مرة واحدة. سيحمّل الصور الخمس المرخصة إلى `public/images/` ويحوّل الصفحة تلقائياً إلى المسارات المحلية، مع بقاء بيانات الإسناد والترخيص في المحتوى.
